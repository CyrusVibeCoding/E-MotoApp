# RepRide

Social riding app for e-bike and e-moto riders. Home contains the native riding map, solo recording, consented group rides, and opt-in friend locations. Friends contains rider search, requests, follows, profiles, and text activity. Garage owns bike details, build color, and installed mods. Profile contains identity, local statistics, achievements, build, ride history, activity, and sharing controls.

Existing durable recording, tracking-task startup, local storage keys, anonymous group identity, and group RPC remain the foundation. Profiles default private. Completed rides created after profile setup publish automatically to the effective profile audience. Earlier rides require explicit sharing. Published geometry is sanitized before transmission. Leaderboards have a separate opt-in.

Current preview uses the existing device-scoped anonymous identity and native map provider. Account recovery, photo/video publication, automatic detection, wheelie measurement, Specd 3D, and physical-device acceptance remain subsequent milestones. The supplied user brief and Obsidian vault are product authority.
